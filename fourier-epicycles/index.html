Fourier Epicycles

The Fourier series allows you to represent a function in a basis of oscillation components cis(2πikt), thus expressing it as z(t) = Σ ck cis(2πikt). A cool way to represent this is to draw circles rotating at a frequency of k, with each circle being connected to the one before, representing a sum. The tip of the last circle can trace out any closed curve (here, it is Da Vinci's Mona Lisa), just like how the Fourier sum is equal to any periodic function.

The sliders change how the image is read: Detail sets how coarsely it is sampled, Minimum stroke size drops small isolated pieces, Edge threshold sets how bright (or opaque) a pixel must be to count as an edge, and Circles sets how many circles are used. Click the drawing to restart it.
