Showcase of pub_style

This is my own package for making prettier plots. I like how plots made with PGFplots look; I think matplotlib figures look unpolished. This module defines a custom style for matplotlib that is inspired by PGFplots and is tuned for reports/publications by default. Features include accessible colour palettes, optional LaTeX fonts, sensible dimensions, and improved styling for fonts, axes, ticks, and the legend—all chosen to look good in a paper. The name was originally supposed to mean "a plot style for publications", but I much prefer the meaning of "plots cooked up pub style", so that's the canon now.

This is a demo of pub_style package. I have the plots and then the codes below. Note that using fig.savefig('figure'), that saves as figure.pdf. To save an SVG, for example, do fig.savefig('figure.svg'). Also click on the link of the headers to view the PDF output.
