Showcase of pub_style

This is my own package for making prettier plots. I like how plots made with PGFplots look; I think matplotlib figures look unpolished. This module defines a custom style for matplotlib that is inspired by PGFplots and is tuned for reports/publications by default. Features include accessible colour palettes, optional LaTeX fonts, sensible dimensions, and improved styling for fonts, axes, ticks, and the legend—all chosen to look good in a paper. The name was originally supposed to mean "a plot style for publications", but I much prefer the meaning of "plots cooked up pub style", so that's the canon now.

The package is very simple—it runs on top of matplotlib, and in most cases, importing matplotlib is not necessary. The standard use loop is calling pub_style.use() once to load the global style settings. Then, for every separate figure, fig, ax = pub_style.new_figure(), which gives a Figure for fig and either an Axes or an ndarray of Axes for ax, which are what you would use for matplotlib. After plotting your data, you can call fig.savefig('figure') (which by default saves files to PDFs; do fig.savefig('figure.svg') to save as an SVG) to export the figure.

There are also some helper functions. pub_style.copy() copies the figure as a PNG to the clipboard (macOS only), which is really handy for making presentations. pub_style.griddify() applies a stylized grid to a given set of Axes or to the current axis.

The package uses LaTeX by default, so mathematical symbols can be added most simply with LaTeX's math mode and Python's raw strings, such as r"$y = \cos(x)$". The package also uses Paul Tol's colour schemes as they are print-friendly and colourblind-safe.

Below is the full API reference (directly copied from the source code) and further below are some example creations.

API Reference

use(usetex=True, serif=False, presentation=False, colours='bright', custom_preamble=None, N=10)

Applies the pub_style rcParams globally. Call once at the top of a script, before creating any figures.

  • usetex — use LaTeX for text rendering (requires a working LaTeX install). Default True.
  • serif — loads Helvetica + sfmath when False, or newtxtext/newtxmath (Times-based) when True. Also sets font.family. Ignored when usetex=False — use use_font() instead.
  • presentation — scales up axis/title label sizes for slides. Default False.
  • colours — a Tol colorset key (e.g. 'bright', 'muted'), a Tol or matplotlib colormap name (resampled into N colours), or an explicit list/tuple of colours.
  • custom_preamble — overrides the LaTeX preamble chosen by serif, for loading a font not covered by the two presets.
  • N — number of colours to sample when colours is a colormap name. Ignored otherwise. Default 10.

use_font(name, serif=None)

Sets the matplotlib font when not using LaTeX — a convenience for after calling use(usetex=False), since matplotlib's default fonts are a poor substitute for a proper typeset font.

  • name — the font family name (e.g. "Helvetica", "Times New Roman"), must be installed and discoverable by matplotlib's font manager.
  • serif — registers the font as serif or sans-serif. If None, inferred from the current font.family rcParam as set by use().

new_figure(nrows=1, ncols=1, despine=True, minor_ticks=False, width_mm=86, ratio=None, **kwargs)

Creates a new figure with one or more subplots at publication-appropriate dimensions. Width is given in mm and converted to inches; height is derived from the aspect ratio. Uses matplotlib's constrained layout engine to avoid clipped labels/titles. Extra kwargs are forwarded to plt.subplots() (e.g. sharex, gridspec_kw).

  • nrows, ncols — grid of subplots. Default 1, 1.
  • despine — removes the top/right spines for a cleaner, PGFplots-like look, with ticks pointing in and out. When False, keeps all four spines with ticks pointing in only. Default True.
  • minor_ticks — shows minor ticks on both axes. Default False.
  • width_mm — figure width in mm. Single-column figures are typically 85–90 mm, full-width 180–183 mm. Default 86.
  • ratio — width/height aspect ratio. Defaults to GOLDEN_RATIO * ncols / nrows, so each subplot cell is golden-ratio shaped. Use 1.0 for square.

A Figure and either a single Axes or a 2D array of Axes.

show()

Displays all open figures — a thin wrapper around matplotlib.pyplot.show() so you don't need to import matplotlib directly.

copy(fig=None, dpi=300)

Copies a figure to the clipboard as a PNG. macOS only — handy for pasting straight into presentations.

  • fig — figure to copy. If None, uses the current active figure.
  • dpi — resolution of the copied image. Default 300.

reset()

Resets matplotlib's styling back to its defaults.

griddify(ax=None, major=True, minor=True, major_alpha=0.6, minor_alpha=0.3)

Adds nice-looking grid lines to one or more axes. Not something you'd want in a paper or report figure, but useful for "large" figures or data exploration.

  • ax — a single Axes, an ndarray of Axes (as returned by new_figure()), or None for the current active axes.
  • major / minor — show major/minor grid lines. Both default True.
  • major_alpha / minor_alpha — opacity of major/minor grid lines. Default 0.6 / 0.3.
