\activity{Ultrashort Laser Pulse Measurements}{Attosecond Condensed Matter Experiments Lab}{May 2026 -- Present}
Main focus is frequency-resolved optical gating via ``Kerr instability amplification''. Performed experiments, data acquisition, reconstruction and other analysis, wrote software, and wrote simulations. The long-term goal for this project is to eventually measure damage effects/plasma density in crystals wrought by KIA.

\activity{Laser-Induced Breakdown Spectroscopy on Bacterial Cells}{Rehse Lab}{Oct. 2023 -- Present}
The main focus is to develop a quasi-instantaneous diagnostic test for bacterial diseases, such as bacterial meningitis, using laser-induced breakdown spectroscopy. Performed experiments, acquired data, applied chemometric data analysis and machine learning techniques for classification, fixed lasers, and prepared biological samples.
