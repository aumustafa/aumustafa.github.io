Fourier Drawing

The Fourier series allows you to represent a periodic function z(t) in a basis of oscillation components cis(2πkt), thus expressing it as z(t) = Σ ck cis(2πkt). A cool way to represent this is to draw circles rotating at a frequency k, with each circle being connected to the one before, representing a sum. The tip of the last circle can trace out any closed curve, just like how the Fourier sum is equal to any periodic function.

The drawing script has been created by AI, but I have written and confirmed the explanatory text.
